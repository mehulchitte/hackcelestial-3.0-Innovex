RESORTOS AI - SIMPLE SETUP

1. Copy .env.example to .env
2. Put your Nugen API key in:
   NUGEN_API_KEY=your_key

3. IMPORTANT:
   You do NOT need to create an aligned Nugen model for the AI to work.
   The app automatically uses:
   NUGEN_MODEL_ID (if alignment succeeded)
   OR
   NUGEN_BASE_MODEL=nugen-flash-instruct

4. Optional second real-AI provider:
   GEMINI_API_KEY=your_google_ai_studio_key
   GEMINI_MODEL=gemini-3.8-flash

5. Start:
   python run.py

6. Open the Nugen Intelligence page and press "Run Nugen Inference".

The app keeps the local deterministic fallback only as a last-resort safety net.
No API key is embedded in the project.
